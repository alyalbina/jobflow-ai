# JobFlow AI — запуск на Windows

## Установка и запуск

1. Установите Python 3.12 с [python.org](https://www.python.org/downloads/windows/), если его ещё нет. При установке включите Python Launcher.
2. Распакуйте проект в отдельную папку. Дважды нажмите `Install-Windows.cmd`. Он создаст локальное окружение и установит зафиксированные зависимости.
3. Нажмите `Start-JobFlow.cmd`. Откроется приватное приложение на `127.0.0.1:8765`. Окно запуска оставьте открытым. Ctrl+C останавливает сбор.

Запуск создаёт одноразовую локальную ссылку авторизации. Она не попадает в логи и публичное демо. Простое открытие адреса без запуска не даёт доступ к базе. Приложение рассчитано на одного владельца и доверенную Windows-учётную запись; не публикуйте его через туннель или на `0.0.0.0`.

## Одно конкретное подключение Telegram

Остановите JobFlow. Войдите лично на [my.telegram.org](https://my.telegram.org), откройте **API development tools**, создайте собственное приложение и получите `api_id` / `api_hash` по [официальной инструкции](https://core.telegram.org/api/obtaining_api_id). Заполните `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` только в локальном `.env`. Не отправляйте их, коды входа, пароль 2FA или session-файл в чат.

Нажмите `Connect-Telegram.cmd` и в его локальной консоли лично введите номер, код Telegram и пароль 2FA, если он включён. Затем запустите JobFlow заново, включите нужные каналы в **Settings → Telegram sources** и нажмите **Sync now**. Проверка `accessible` означает доступ из вашего аккаунта; наличие публичной веб-страницы само по себе этого не доказывает.

Первый импорт ограничен 50 сообщениями на включённый источник (настройка 1–200). Последующие циклы дочитывают новые сообщения порциями без пропусков позиции. Для первоначальной проверки включите 1–2 источника. JobFlow не вступает в закрытые каналы и не отправляет сообщения рекрутерам.

## Резюме и отклики

В **CV Studio** загрузите текстовый PDF или DOCX. Извлечённые предложения сначала имеют статус `inferred`: проверьте оригинал и нажмите **Approve exact CV quote**. Свою утверждённую формулировку добавляйте как `self-reported`; это не доказательство из файла.

В Settings заполните роли, географию, опыт и языки. Неизвестное разрешение на работу оставляйте пустым. В Discover откройте вакансию, прочитайте **Why it matches / Potential gaps / Unknowns**, при необходимости исправьте поля и сохраните в CRM. Подготовьте письмо, проверьте его и отправьте самостоятельно по оригинальной ссылке. Отметьте **Applied** только после фактической отправки и включите подтверждающий флажок.

Сохранённые тексты имеют ссылки на версии CV. Адаптация создаёт отдельный extract, не заменяет биографию. DOCX/PDF экспорт доступны локально. Факты сохраняют утверждённый язык: для полностью английского письма добавьте утверждённые английские формулировки.

## Локальная AI-модель

Basic Mode работает без LLM. Для Local Mode установите [Ollama для Windows](https://docs.ollama.com/windows), запустите установленную модель и заполните `OLLAMA_MODEL` в `.env`. Адрес разрешён только локальный `127.0.0.1:11434` / `localhost:11434`. В Settings выберите Local Ollama. Недоступность сервиса или неподдержанные evidence IDs приводят к Basic fallback.

На этом ноутбуке проверена уже установленная `qwen3:8b` (5.2 GB на диске), доступная физическая RAM — около 13.9 GB. Проверка на вымышленных фактах не является оценкой общего качества. Модель существенно занимает память; при нехватке ресурсов используйте Basic Mode. JobFlow не скачивает модели автоматически и не обращается к платным API.

## Личные уведомления

Создайте собственного бота через официальный [@BotFather](https://t.me/BotFather), лично нажмите Start в нём, заполните локальные `TELEGRAM_BOT_TOKEN` и свой `TELEGRAM_CHAT_ID`. Включите личные уведомления в Settings. Бот присылает только настроенный дайджест вакансий и записанные follow-up/interview reminders. Не используйте чужой chat ID. Неопределённая доставка не повторяется автоматически; проверьте чат прежде, чем предпринимать повторную отправку.

## Бэкап и удаление

В Settings скачайте приватный SQLite backup. Он содержит тексты и записи; исходные бинарные CV храните отдельно из `private/cvs/`. Восстановление требует остановленного Telegram-подключения. Если приложение активно мониторит, сначала остановите его, временно уберите API-настройки из `.env`, запустите, восстановите, затем верните настройки.

Удаление требует точной фразы **DELETE MY LOCAL DATA**. Оно удаляет записи, загруженные CV и локальную Telegram-сессию. Скачанные бэкапы, `.env` и авторизация на стороне Telegram требуют отдельного управления. После удаления перезапустите приложение.

## Частые ситуации

- Пустая лента: проверьте авторизацию, включённые источники и фильтры; Basic Mode не создаёт реальные вакансии самостоятельно.
- CV без текста: сканированный PDF требует OCR вне JobFlow; загрузите текстовую версию.
- Flood wait: дождитесь указанного срока, не ускоряйте повторные запросы.
- Недоступный канал: исправьте username или отключите; приложение не обходит доступ.
- Ошибка окна запуска: сохраните текст ошибки без секретов; `.env` и `.session` не отправляйте.
